## FAQ

### Is OmniPatch safe to use on my computer?

OmniPatch is designed with safety in mind. It does not install any persistent services or modify system files. All changes are confined to the target application's local data. You can use the provided rollback feature at any time to revert changes.

### Which AI applications are currently supported?

OmniPatch supports ChatGPT (web and desktop), Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI Assistant. Support for new applications is added regularly.

### How often is OmniPatch updated for compatibility?

We aim to release updates within 48 hours of any major change to a supported AI application. Check the repository's 'Releases' section or enable notifications for automatic alerts.

### Does using OmniPatch violate the terms of service of these AI apps?

This tool modifies local application behavior. Users should be aware that using such tools may be against the Terms of Service of the respective platforms. OmniPatch is provided for educational purposes.

### Will this affect my AI account or data stored in the cloud?

OmniPatch operates entirely on your local machine. It does not interact with cloud accounts, servers, or stored data. Your conversations and data remain untouched.

### Can I still receive updates for the patched applications?

Yes. OmniPatch is designed to survive application updates. However, major rewrites of the target app might require a patch update from us. The tool will notify you if a new patch is needed.

### What if I encounter an issue or need support?

Please open an issue on the GitHub repository with detailed information. Our community and maintainers will help troubleshoot. Ensure you provide your OS version and which application you are patching.

### Is there a version for macOS or Linux?

Currently, OmniPatch is a Windows-only application. There are no official plans for other operating systems at this time, but the repository accepts contributions.
